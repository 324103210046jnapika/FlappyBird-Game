# Flappy Bird Game

A Java-based Flappy Bird game developed using Java Swing and the BlueJ development environment. The project demonstrates Object-Oriented Programming, event-driven programming, and multithreading through an interactive game.

## Technologies Used

- Java
- Java Swing
- Multithreading
- Object-Oriented Programming (OOP)
- BlueJ

## Features

- Interactive Flappy Bird gameplay
- Bird movement and flap controls
- Gravity and collision detection
- Randomly generated pipes
- Score and high-score tracking
- Multiple lives
- Level progression with increasing difficulty
- Collectible coins
- Combo scoring system
- Power-ups
- Pause and resume functionality
- Game-over and restart functionality
- Statistics tracking
- Persistent game data
- FPS monitoring

## Multithreading

The game uses multiple threads to manage different game operations independently, including:

- Bird movement and physics
- Pipe movement and generation
- Coin movement and spawning
- Power-up movement and spawning
- Screen repainting

This demonstrates the use of Java multithreading in an interactive application.

## Development Environment

This project was developed, tested, and executed using the **BlueJ Java development environment**.

## How to Run

1. Download or clone this repository.
2. Open the project in **BlueJ**.
3. Compile the Java source file.
4. Run the main class.
5. Use the keyboard controls to play the game.

## Controls

| Key | Action |
|---|---|
| `Space` | Flap |
| `W` | Flap |
| `P` | Pause / Resume |
| `R` | Restart after Game Over |
| `Esc` | Return to Menu |
| `S` | Toggle Sound in Settings |

## Project Highlights

This project was developed to understand how Java can be used to build an interactive graphical application while applying:

- Java Swing

- Collision Detection
